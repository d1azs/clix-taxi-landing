# Clix Taxi Landing Page

Official React-based landing page for the Clix Taxi platform. This project provides an interactive and responsive presentation of the Clix Taxi ecosystem for both passengers and drivers.

## Technologies Used
- React
- Vite
- Custom CSS / Animations

## Setup Instructions
1. Install dependencies: `npm install`
2. Start the development server: `npm run dev`
3. Build for production: `npm run build`
